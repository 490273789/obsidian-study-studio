# StudyStudio

一个基于 FSRS 算法的 Obsidian 闪卡学习插件，帮助你高效学习和复习知识点。

## ✨ 功能特性

- 🏷️ **自定义标签扫描** - 自动扫描带有指定标签的文件作为题库
- 📚 **多题库管理** - 每个文件对应一个题库，方便分类管理
- 🧠 **FSRS 算法** - 采用先进的 FSRS6 间隔重复算法，科学安排复习计划
- ⌨️ **快捷键支持** - 完整的键盘快捷键，提升学习效率
- 📱 **移动端兼容** - 支持桌面端和移动端使用
- 🎨 **优美界面** - 平滑动画过渡，优雅的用户体验
- 📖 **词典查询** - 内置有道、剑桥、沪江在线词典，桌面端可导入 MDX/MDD/EUDIC 本地词典离线查询，支持 AI 释义与收藏单词

## AI 翻译

在插件设置的「AI 翻译」页启用功能，配置翻译方案后点击「保存翻译设置」。DeepSeek、百炼方案选择「AI 引擎设置」中已有的引擎配置；有道翻译使用专用接口及 Obsidian 钥匙串引用，与有道大模型网关分开配置。

通过侧边栏的「学习工作台」图标、首页里的「AI 翻译」条目或「AI 翻译」命令打开独立视图，也可用「翻译选区」命令预填文字。点击「翻译」或按 Ctrl/Cmd + Enter 后，启用的方案并行翻译，按设置顺序显示结果，可逐项复制。支持中英双向、思考模式、自定义提示词和 Token 用量。

选区预填不自动发送请求，也不修改原笔记。翻译结果仅缓存在内存中，清空或关闭最后一个翻译视图后重置，不保存翻译历史。连接测试会发送少量文字；真实翻译和测试均可能产生厂商费用。

## 📝 卡片格式

在 Markdown 文件中使用以下格式创建闪卡：

```markdown
#wordTag

## science

??
n. 科学；自然科学；理科
::
/ˈsaɪəns/
root: sci- = know 知道

The study of science has made great progress in recent years.
近年来科学研究取得了巨大进展。
;;

## apple

??
n. 苹果
;;
```

### 格式说明

- 文件开头需要有一个标签（如 `#wordTag`），用于标识这是一个闪卡题库
- `??` 上方是正面，下方是背面，标记需要独占一行
- `::` 后面是解释内容，解释可选；没有解释时可以省略 `::`
- `;;` 是单张卡片的结束标记，必须独占一行
- 正面、背面和解释都支持完整的 Markdown 语法
- 正常模式会用正面出题、背面作答；反转模式会用背面出题、正面作答，解释始终跟随答案显示

## ⌨️ 快捷键

| 快捷键 | 功能                    |
| ------ | ----------------------- |
| `空格` | 显示答案 / 选择"记得"   |
| `1`    | 忘记（1分钟后再次出现） |
| `2`    | 困难（1天后复习）       |
| `3`    | 记得（3天后复习）       |
| `4`    | 轻松（10天后复习）      |
| `5`    | 熟练（21天后复习）      |
| `6`    | 上一题                  |

## ⚙️ 设置选项

- **闪卡标签** - 设置要扫描的标签（默认 `#wordTag`）
- **每日新卡数量** - 每天学习的新卡片最大数量
- **每日复习数量** - 每天复习的卡片最大数量
- **学习顺序** - 顺序学习或乱序学习
- **FSRS 参数** - 可调整目标记忆保持率和最大复习间隔
- **词典** - 启用词典查询，管理词典来源与排序、收藏文件路径、有道接入方式与 AI 释义引擎

## 🚀 使用方法

1. 安装并启用插件
2. 创建一个 Markdown 文件，按上述格式添加闪卡内容
3. 点击左侧栏的「学习工作台」图标，从首页进入「闪卡学习」，或直接使用命令面板中的「闪卡学习」命令
4. 点击刷新按钮扫描题库
5. 选择一个题库开始学习

## 🔧 开发

开发工具链使用 Vite Plus。Node.js 的精确版本见 `.node-version`，pnpm 的精确版本见 `package.json` 的 `packageManager`；本地开发与 CI 使用相同版本。

```bash
# 安装依赖
pnpm install

# 开发模式（监听文件变化）
pnpm run dev

# 构建生产版本
pnpm run build

# 格式、Lint、类型检查及完整测试
pnpm run check:all
```

构建、测试、Lint 和格式化配置统一位于 `vite.config.ts`。`pnpm run dev` 监听构建 Obsidian 插件，`pnpm run build` 输出根目录的 `main.js` 和 `styles.css`。直接执行 `vp dev` 会启动 Vite 网页开发服务器；插件开发请使用上述 pnpm 脚本。
