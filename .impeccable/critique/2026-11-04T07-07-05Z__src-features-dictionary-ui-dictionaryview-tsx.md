# 英语字典设计评审

查词入口清楚，主要阻力出现在结果页。以截图里的 `purpose` 为例，读者得从 20 条编号中自己辨认哪些是词义、哪些是同义词或例句。词典最应该帮学习者完成的判断，落回了学习者身上。

## 设计判断与优点

中文释义、英美音分开播放、词条收藏都符合 Study Studio 的学习场景。查词按钮明确，重查和切换来源方便，底部也保留了来源说明。结果正文的组织仍接近接口数据展示。两个 TSX 文件的 Impeccable 静态扫描均返回 0 项，重点问题由截图和数据到列表的渲染链路确认。

## 优先问题

1. **[P1] 按义项呈现英英释义。** 第 1 条是 `n.`，第 3 条是 `intent`，第 11 条是例句，第 20 条是音标。递归取出的文本被交给同一个有序列表。让词性做小标题，只给可确认的义项编号，把同义词和例句放到各自义项下。来源结构不足时保留原文，避免猜测归属。适合 `$impeccable shape`。
2. **[P1] 让结果有自己的词头。** 截图里 `purpose` 只出现在搜索框和历史。输入可以独立编辑，旧结果仍可能留在屏幕上。结果从实际词头开始，紧接音标和中文释义，收藏与复制放到词头同一行。适合 `$impeccable layout`。
3. **[P2] 把首屏注意力还给释义。** 截图里有 8 个可见历史词、各自的删除按钮，以及 7 个详情标签。收起历史到 3–4 项加「更多」，把逐条删除放进历史列表。来源切换与词条内导航分层，优先露出英英释义、短语、词形等主要入口。适合 `$impeccable distill`。
4. **[P2] 让两个清除动作说明各自范围。** 搜索框内的 × 只清空输入，右侧垃圾桶会清空输入和当前结果，二者都叫「清空」。改成「清空输入」和「清除当前查询和结果」，同步更新提示和无障碍名称。适合 `$impeccable clarify`。

## 使用路径与细节

- **第一次查词**容易找到查询按钮，但「6000 Images」和无文字的批量收藏按钮需要猜测。查询成功后，缺少词头和词义分组又让用户停下来确认。
- **频繁查词**可以用回车和方向键提速，但每次阅读都要重新区分定义、例句和同义词。
- **键盘与读屏**用户可能先经过大量历史词及其删除按钮。读屏会把词性、例句和音标读作并列列表项。实际焦点、读屏输出和亮暗主题对比度仍待验证。
- 粉色历史标签和列表编号都比较抢眼。可降低辅助元素的颜色权重，并在 Obsidian 主题下核对。一个检验问题是，用户在窄分栏里能否不滚动就看到词头、发音和第一条中文义项？
