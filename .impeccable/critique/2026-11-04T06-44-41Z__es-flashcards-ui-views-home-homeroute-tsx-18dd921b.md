# 闪卡首页设计评审

首页有明确的「继续学习」入口，但最醒目的任务信息是 2,344 张待学。首页优先回答今天要做多少、哪些需要复习，再交代整组进度。

| ------------ | ----: | ------------------------------------------------ |
| 系统状态可见 |     2 | 有进度和足迹，首屏缺今日计划和到期量             |

## 设计判断

续学区、足迹、状态分组和源文件入口有 Obsidian 学习工具的特点。青色实心按钮建立明确起点，固定动作列方便扫描，进度和状态有文字辅助。大数字和重复浅青按钮让首页更像管理库存。用户先看到「接着学」获得连续感，接着可能把 2,344 张理解成本次任务。七个图标工具和列表顶部三段说明增加识别与记忆成本。独立源码检测扫描 Home 目录，规则命中 0 条。视觉判断依据用户提供的桌面截图。

## 优先问题

1. **P1｜首页把总库存摆在今日任务的位置。** 首屏和首行都显示 2,344，未标清是未学新卡。优先显示学习设置已有的「今日计划 N 张 · 新卡 N 张 · 计划复习 N 张」，把剩余新卡留在卡组进度。建议 `$impeccable layout`。
2. **P1｜新卡进度盖住复习状态。** 「已学完」按新卡归零分组，默认折叠，仍可能有到期复习。当前推荐按已开始优先、剩余新卡最多排序。先将分组改为「新卡已学完」，在卡组行与折叠摘要显示到期数，并区分到期库存和受每日上限约束的计划量。若首页承担每日复习入口，再定义推荐优先级。建议 `$impeccable shape`。
3. **P2｜更多操作遮住卡组名。** 菜单锚定省略号或只替换右侧按钮区，保留可见卡组名，也在操作组的可访问名称中包含卡组名。建议 `$impeccable harden`。
4. **P2｜模式说明离选择太远。** 收轻重复操作的色块，让拼写在空间允许时显示文字，把「练习不改变下次复习时间」等提示贴近对应选择。建议 `$impeccable distill`。
5. **P2｜卡组焦点名称与键盘用途不一致。** 行的名称为「打开题库」，同时承载键盘排序。让排序和学习有各自明确的入口，实机验证 Space、Enter 和焦点顺序。建议 `$impeccable harden`。

## 使用者视角

初次使用者点进去才知道今天的学习规模。每日回访者无法在首页找出今天到期的卡组。键盘和读屏用户会遇到打开与排序的语义冲突。实机焦点、读屏、对比度和窄面板尚未验证。

## 细节与取舍

统一「学习 2 次」「总时长 18 秒」的间距。学习足迹的作答次数与计划的卡片张数分别表达。若首页只突出一个数字，优先选能帮助用户决定今天怎么开始的数字。
