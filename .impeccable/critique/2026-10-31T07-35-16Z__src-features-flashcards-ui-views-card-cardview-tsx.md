### Design Specificity Verdict (设计特异性评定)

**LLM 设计评审结论**：
当前的答题界面更接近于“通用的工单审查/表单系统”，严重缺乏沉浸式英语学习工作台的质感。

- **卡片隐喻消亡**：页面被生硬切成 3 个带边框的方块容器（问题、答案、解释），丧失了抽认卡（Flashcard）作为一张连贯卡片的整体感。
- **冗余彩标噪音**：右上角醒目的“问题”（青）、“答案”（紫）、“解释”（黄）标签属于典型的后台管理系统思维。对于英语学习者而言，看到单词无需被告知是“问题”，看到中文无需被告知是“答案”，它们占据了首屏黄金位置却零信息增量。
- **词典动线支离破碎**：发音按钮孤立在最上方，单词在中间，音标却沉底在第三个盒子内，中文释义夹在其中。现代英汉词典中“单词 + 发音 + 音标 + 词性释义”的感官复合体被容器边界彻底肢解。
- **彩虹色谱失控**：一屏之内同时并存红（忘记1）、橙（困难2）、蓝（记得3）、青（轻松/主色）、绿（熟练5）、紫（答案）、黄（解释），直接违背了 `DESIGN.md` 中“_Don't 用无状态含义的彩色文字、厚重阴影或大面积强调色代替内容层级_”的核心原则。

**确定性静态扫描 (Deterministic scan)**：

- 静态 AST 源码扫描 0 报错（全部使用 `--fc-*` 语义变量）。
- CSS 产物深度追溯命中 **1 项 warning (`side-tab`)**：`src/core/styles/cardStack.scss:48` 在 `.flashcard-question`、`.flashcard-answer`、`.flashcard-explanation` 上设置了 `border-inline-start-width: 4px;`，在圆角矩形上形成了生硬的不对称厚边，是典型的模板化 "side-tab accent" 痕迹。
- 可用性排查发现 **1 项可读性隐患 (`undersized-ui-text`)**：底部评分按钮快捷键提示 `{btn.shortcut}` 使用了 `--fc-font-2xs` (10px)，低于 11px 的 WCAG 可读性底线。

**可视化覆盖层 (Visual overlays)**：

- 目标为运行于 macOS Electron 架构下的 Obsidian 桌面端插件，未启用本地 DevTools 远程调试端口 (`9222`)，且无外部可访问的独立 URL。依据规范安全跳过 CDP 蒙层注入，依托源码追踪与实机截图比对提供精准证据。

### Overall Impression (总体印象)

答题界面具备坚实的 FSRS 间隔调度算法和完整的快捷键基础设施，但在信息架构与视觉层级上陷入了“表单式组件堆砌”的误区。它没有兑现 `DESIGN.md` 承诺的“**安静的学习工作台：克制、清晰、紧凑，让阅读内容优先**”，反而用 3 个独立大方盒、3 枚高饱和胶囊标签和 5 个并列彩色按键制造了严重的认知摩擦。最危险的是，**翻卡后空格键默认映射为“困难（1天间隔）”**，严重逆反了抽认卡领域全行业通用的肌肉记忆。

### What's Working (做得很棒的亮点)

1. **确定性的未来复习间隔呈现**：评分按钮清晰标注了 FSRS 算法计算出的具体复习时间（`1分钟`、`1天`、`3天`、`10天`、`21天`），彻底打破了间隔算法的黑盒焦虑，赋予自律学习者极高的时间可预期性。
2. **完整的按键闭环与状态防护**：支持从翻卡、1-5评分到撤销（RotateCcw）的全键盘操作流；顶栏整合了自动朗读开关、卡片编辑与安全删除入口，操作闭环扎实稳健。

### Priority Issues (优先级问题清单)

- **[P1] 致命快捷键违背心智模型：空格键被绑定至“困难 (Rating 2)”而非“记得 (Rating 3 / Good)”**
    - **Why it matters**: 严重背离 Anki、SuperMemo 等全球抽认卡事实标准。习惯盲打空格过卡的用户会将所有卡片惩罚性判定为“困难”（1天重复），造成复习队列迅速爆炸，直接破坏 FSRS 学习曲线。
    - **Fix**: 在答案翻开态下，将空格键重定向绑定为默认通过项“记得 (Rating 3)”；在“记得”按钮上明确标注 `3 / 空格`。
    - **Suggested command**: `/impeccable clarify`

- **[P1] 视觉过度容器化与边框噪音：三段式独立方块与 4px side-tab 破坏沉浸感**
    - **Why it matters**: 3 个带边框方盒（`.fc-panel`）加 4px 左侧加粗线（`border-inline-start-width: 4px`）把内容切得支离破碎，把“卡片”变成了“工单”。
    - **Fix**: 合并为一个连贯呼吸的单体卡片表面（Card Surface），移除 4px 左侧突兀色条，改用克制的 1px 细线或优雅留白分隔问答区域。
    - **Suggested command**: `/impeccable quieter`

- **[P1] 冗余标签噪音与彩虹配色失控：“问题/答案/解释”胶囊标签抢夺首屏权重**
    - **Why it matters**: 右上角青、紫、黄三枚彩色胶囊标签毫无信息增量，纯属视觉噪音；整屏 7 种色彩齐发，违背了 `DESIGN.md`“克制、让阅读内容优先”的定位。
    - **Fix**: 彻底拔除右上角三枚无功能意义的彩标；收敛背景与文字色彩，通过字体大小、字重和灰度（`--fc-text`、`--fc-muted`）建立优雅的内容层级。
    - **Suggested command**: `/impeccable distill`

- **[P1] 词典排版动线断裂：发音、单词、音标与释义空间割裂**
    - **Why it matters**: 喇叭按钮独立悬浮于单词上方，音标流落到第三个盒子底部，释义夹在中间，违背了现代词典“词条 + 发音/音标 + 词性释义”的天然认知流。
    - **Fix**: 采用正统词典版式：主词条与发音按钮、音标同行紧凑排列；下方自然呈现词性与中文释义；词根词缀与例句采用次级字号收敛沉底。
    - **Suggested command**: `/impeccable typeset`

- **[P2] 评分决策过载与微文字可读性：5 个平权按钮超出 Cowan 工作记忆极限**
    - **Why it matters**: 5 个按钮等宽平铺，迫使用户在“记得 / 轻松 / 熟练”之间进行高频微决策，拖慢心流；且快捷键提示文字为 10px（低于 11px WCAG 底线）。
    - **Fix**: 确立层级：将“记得 (Rating 3)”设为唯一的突出主操作（Primary），弱化其余选项为次级按钮；将快捷键字体提升至 `--fc-font-xs` (11px)。
    - **Suggested command**: `/impeccable distill`

3. **“在答题翻卡的最后两秒钟，用户的大脑应当停留在‘我真正掌握了这个单词吗’的知识反思中，还是被困在‘我该点第3个还是第4个按钮’的选择纠结里？”**
