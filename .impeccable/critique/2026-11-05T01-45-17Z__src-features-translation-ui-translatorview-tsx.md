1. **[P1] 给未配置状态一个明确的下一步。** 全部方案不可用时，在主操作区显示「配置翻译方案」，原文仍可输入和保留。部分方案可用时，按钮注明本次可运行的方案数，其余方案就地说明缺什么。建议命令：`onboard`。
2. **[P1] 让结果标签讲清楚当前在看什么。** 实际选中的是「专业对照」，截图中更抢眼的粉色却在两个未选中的模型上。标签只切换结果，提交仍会处理所有已启用方案。建议改成「全部译文」，给选中项清晰的边框或下划线，并在提交处标注范围。建议命令：`clarify`。
3. **[P2] 让翻译按钮靠近输入。** 当前窗口里从输入提示到按钮将近一屏，右侧还重复出现两张占位卡、八个禁用图标和两条空底栏。缩短空态输入区，把按钮和快捷键放在输入区附近，长文本再扩展。成功后优先露出「复制译文」，有两条结果后再开放差异高亮。建议命令：`layout`。
4. **[P2] 修正提示对比度和控件语义。** 实机浅色主题下，粉色原文占位提示与底色的对比度约为 2.0:1。改用中性次要文字，保留可见焦点。复制按钮初始名称用「复制译文」，操作后再反馈「已复制」。单方案视图有重复的面板 ID，修正后验证键盘切换与差异开关的可访问状态。建议命令：`harden`。

首次用户会在「到底能不能翻译」处卡住。熟练用户可能把选中某个模型理解为仅使用该模型。低视力或键盘用户会遇到偏淡的提示、结果标签和差异开关的状态问题。首屏同时展示三个结果标签、差异开关和八个禁用动作，增加了还未开始翻译时的判断负担。
