# 听说练习

首版用于英语短句和短文：添加仓库音频，导入或生成字幕，校对后逐句听与跟读。电脑和手机使用同一份仓库材料和练习记录，移动端以前台练习为准。

## 使用

在首页点击耳机按钮，或执行“听说练习”打开命令。选择仓库内 MP3、M4A 或 WAV，可配 SRT/VTT；没有字幕时，可以只提供音频，或附上基本逐字一致的英文原文。原文可以粘贴，也可以从 TXT/Markdown 载入后编辑。

设置中的字幕生成可选两种服务：阿里云百炼北京地域的同步语音识别（Workspace ID、模型与密钥），或标准 OpenAI 兼容的 `/audio/transcriptions` 服务（Base URL、模型与密钥）。百炼可用模型为 `fun-asr-flash-2026-06-15`、`qwen-audio-3.1-asr-flash`、`qwen-audio-3.0-asr-flash`；异步、WebSocket 与异构响应模型不支持。OpenAI 兼容服务默认 `whisper-1`，需要返回词级时间戳；只返回文本的服务无法自动匹配原文。生成会上传音频并产生服务用量；原文仅用于本地匹配。已保存的字幕和音频不需要联网即可练习。密钥需要在使用生成服务的设备上配置。

生成支持不超过 10 分钟、50 MiB 的材料。系统转换为 16 kHz 单声道 WAV，按 60 秒分段、相邻重叠 1 秒处理，原文件不变。界面显示已完成分段；中断后重新读取原音频，内容指纹相同时复用已完成结果。草稿同时记录所用服务（provider、模型、端点），切换服务后不会复用旧结果。服务未返回词级时间戳时，使用识别分句结果并提示人工校对，不做词级时间估算。取消只终止本地等待，已提交请求可能仍被服务计费。不会自动重新提交收费请求。

校对页可以试听、修改文字和起止时间、添加或删除片段。标为待校对的片段需修正并确认；没有有效时间的片段需定时或删除。保存生成新的 `.practice.srt`，已有同名文件时编号，不覆盖旧字幕。字幕绑定保存失败会显示错误并保留草稿。

逐句模式在片段末尾暂停，跟读后手动下一句；整篇模式连续播放。支持倍速、难句星标与筛选、隐藏原文及当前片段揭示、整体字幕偏移。关闭页面或切后台暂停，恢复页面不自动播放。焦点在练习面板时，空格播放/暂停，左右方向键切换片段；编辑控件不拦截这些按键。

## 数据与边界

音频及字幕文件是内容来源；独立的 `audioPractice` 数据分区保存材料引用、进度和练习偏好。依赖使用者现有同步工具同步仓库附件和插件数据；以单设备轮流练习为边界，不处理双设备同时编辑合并。外部同步到达后暂停并读取新状态。

生成草稿和已完成分段保存在仓库作用域的设备本地存储，不同步音频字节或 API Key。换设备可继续已保存材料的练习，不能继续另一设备未完成的生成任务。文件改名更新引用；字幕修改仅保留能唯一精确对应的难句，失效标记会提示。

首版不包含录音、发音评分、听写、翻译、后台播放、耳机遥控或闪卡联动。对齐不可靠时需要人工校对，不把自动结果解释为精确的声学强制对齐。

## 开发验证

领域测试覆盖逐句边界、进度与同步、字幕往返和校对约束；生成测试覆盖 SSE、分段去重、原文歧义、取消、恢复、OpenAI 兼容响应与 multipart、无词级时间戳降级。发布前需要真实桌面和手机验证解码、生成、片段边界、背景暂停与同步。未持有服务密钥时只运行协议夹具测试，不声称真实服务验证通过。

接口依据：[百炼语音转写 HTTP API](https://help.aliyun.cn/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)、[OpenAI 语音转写 API](https://platform.openai.com/docs/api-reference/audio/createTranscription)。
