# 第 8 批性能基准

日期：2026-10-14。基线为第 7 批后的 `baa331f`，下列路径在首页改动前后使用同一份测试夹具。
运行环境：Node.js v26.11.1、arm64。原始数据见 [batch-8-benchmark.json](batch-8-benchmark.json)。

## 可复跑路径

```bash
pnpm exec vp test run src/features/flashcards/domain/storage/__tests__/performancePaths.test.ts
```

测试也纳入 `pnpm test`。每条路径预热 3 次、记录 20 次，以 JSON 输出 median/p95；
无耗时阈值断言，避免机器负载造成随机失败。断言覆盖无变化刷新零写入、串行作答逐次耐久写入。

夹具包含两个牌组、2413 张已学习且可拼写的稳定身份卡片。运行真实 `SessionLifecycle`、
`DeckHome`、`CardIdentityContinuity`、`FlashcardRepository`、生产 authority adapter 和
`WorkbenchStore`；后端用内存 JSON 字符串模拟序列化/反序列化，**不包含真实磁盘、Obsidian
视图挂载、Markdown DOM 渲染或网络耗时**。时钟固定，计时使用 `performance.now()`。

| 路径                                              | 改前两次运行中位数（ms） | 改后两次运行中位数（ms） |
| ------------------------------------------------- | ------------------------ | ------------------------ |
| 作答：真实学习会话 rating 5 → 提交 → 首页订阅更新 | 5.963 / 6.183            | 5.419 / 5.058            |
| 开视图：首页无变更 refresh / continuity 同步      | 10.144 / 9.208           | 7.149 / 7.142            |
| 改设置：saveSettings → 仓库重载 → 首页订阅更新    | 10.303 / 10.730          | 10.353 / 9.927           |
| 首页局部发布：release-owner 触发共享快照发布      | 0.936 / 0.880            | 0.009 / 0.011            |

局部发布收益最明显：复用挑战计数和同日活动快照，避免扫描 2413 张卡及重建/冻结 371 个
热力图日对象。开视图和作答仍有全量同步/序列化成本；设置路径没有稳定改善结论。
这些是两次本地合成运行的观测值，不作为真实用户耗时或持续性能保证。

## 操作量回归

- 首页挑战计数：20 次局部发布对未变牌组的卡面读取为 0；新 deck 对象、启用标志和删除
  均重新得到正确计数。活动快照覆盖同日身份复用、深冻结、新活动、跨日、时区 offset 失效。
- 发音：100 次相同 `canSpeak` 的 SHA-256 调用 **100 → 1**；音频缓存仍读取 100 次，密钥、
  网络状态、缓存存在性仍即时判断。20 个并发检查共享一次 hash，失败可重试，最多 128 项。
- 词典：3 sources × 50 senses × 10 examples × 20 次输入，重复 `Object.freeze`
  **42,540 → 120**；结果在接收时深冻结一次。结果子树 props 保持身份，React `memo` 可跳过
  输入更新；尚未测量真实 DOM render 次数。
- 选区词典：2-source 查询及 settings refresh 的 `structuredClone` **9 → 2**，含测试 store
  的一次历史保存克隆。会话配置隔离不变，历史仍实时读写，密钥仍即时读取。
- 播放器：单帧 120 个单向 pointermove 的 interaction 回调 **120 → 1**；同帧折返最多 2 次，
  保留跨阈值后回原点、最大化退出、左右缩放和最终保存语义。销毁取消帧，隔离其他指针。
- 翻译：两个视图的引用释放从第一份遗漏变为每份恰好一次；关闭与 feature stop 顺序均覆盖。

上述操作量由各模块聚焦测试验证；尚未在 Obsidian 中人工验证播放、拖动、多视图、词典输入
或午夜/时区变化。
