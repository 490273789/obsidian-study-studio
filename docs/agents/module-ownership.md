## Module ownership

| Area                  | Primary modules                                                                                                                                                                          | Owns                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workbench host        | `src/core/host/workbench.ts`                                                                                                                                                             | Feature registration, view registration and owner-targeted settings signals, owner-scoped settings capabilities, chrome lifetime, view activation, settings-patch commits, the settings-section registry                                                                                                                                                                                                                                                                                                                                                                                                 |
| Feature lifetime      | `src/core/host/featureLifetime.ts`                                                                                                                                                       | Synchronous feature acquisition, first and subsequent settings refresh, fixed-host enforcement, LIFO owned-resource release, and terminal failure semantics                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Workbench features    | `src/features/`                                                                                                                                                                          | Feature declarations, owned runtime acquisition, views, ribbon/commands, settings sections, and feature-owned settings patches                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Obsidian boundary     | `src/core/host/`                                                                                                                                                                         | Plugin/view lifecycle, vault adapters, notices, settings rendering, identity modals                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Shared UI             | `src/core/ui/`                                                                                                                                                                           | UI primitives, the i18n context, and hooks used by more than one feature                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Deck home             | `src/features/flashcards/domain/decks/deckHome.ts`                                                                                                                                       | The home read model (totals, per-deck readiness and effective settings, study history, spelling progress), one required by-id deck read, settings draft, refresh/migration/save/export activity, navigation revalidation, reorder persistence, and word list visit recording; snapshot deck rows stay referentially stable while their content holds, and setup plans plus the resume target are selected from the snapshot by the setup plan methods on `DeckHome` and `ui/homePresentation.ts`                                                                                                         |
| Sessions              | `src/features/flashcards/domain/sessions/sessionLifecycle.ts`                                                                                                                            | The single idle/active/result lifecycle; emits semantic session facts (schedules, records, attempts, challenge progress) through `SessionPersistencePort` instead of document write sets                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Card continuity       | `src/features/flashcards/domain/identity/cardIdentityContinuity.ts`                                                                                                                      | Synchronization, migration, repair, stable card identity continuity, and the two source-edit entries sharing one guard (`sourceEditGuard.ts`), one transaction (`sourceEditTransaction.ts`), and one byte-preserving editor (`cards/cardSourceText.ts`)                                                                                                                                                                                                                                                                                                                                                  |
| Persistence           | `src/core/storage/workbenchStore.ts`, `src/features/flashcards/domain/storage/flashcardPersistence.ts`                                                                                   | The production persistence composition (`createFlashcardPersistence` hands out the deck-home, session, continuity, and tag handles); atomic document serialization, opaque source tokens, `LearningDocumentStore`-owned durable-document revisions/conflict retries/subscriptions, revision-checked writes, `SessionJournalCoordinator`-owned journal watermarks/append/merge/flush, and repository-owned semantic commit validation, journal/document dispatch and failure mapping behind it; migration, FSRS learning state, external reconciliation, local deck-index cache, and semantic transitions |
| Settings              | `src/core/host/settingsSlices.ts`, `src/core/settings/slice.ts`, `src/core/settings/presentation.ts`                                                                                     | The slice registry and composed settings document; the renderer-neutral settings presentation seam, immutable snapshots, interaction validation, and stale-generation rejection                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Outbound port         | `src/core/net/`                                                                                                                                                                          | Request execution, status classification, deadline and cancellation, credential reads, the single host-pinned exception, and the shared Youdao transport (endpoint validation, v3 signing form, JSON/errorCode classification)                                                                                                                                                                                                                                                                                                                                                                           |
| AI engines            | `src/core/ai/`                                                                                                                                                                           | Named provider/model configurations, model discovery, text/image requests, credentials through an injected reader, and per-request timeout/cancellation                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Pronunciation         | `src/features/flashcards/domain/pronunciation/`                                                                                                                                          | Shared configuration snapshot, playback, providers, cancellation, cache and management activity                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Pure card logic       | `src/features/flashcards/domain/cards/`                                                                                                                                                  | Parsing, syntax formatting, byte-preserving card source editing, spelling extraction/comparison                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Audio practice        | `src/features/audio-practice/ui/materialEditSession.ts`, `src/features/audio-practice/domain/audioPracticeRuntime.ts`                                                                    | Per-view listening-material edit session (dialog, draft, file reads/cancellation, commit handshake, failure attribution, catalog refresh); runtime-owned playback, materials, subtitle generation, and draft review; path catalog behind `AudioPracticeCatalog`                                                                                                                                                                                                                                                                                                                                          |
| Learning records      | `src/features/flashcards/domain/history/learningRecords.ts`, `src/features/flashcards/domain/history/studyHistory.ts`, `src/features/flashcards/domain/history/dailyLearningActivity.ts` | One facts-to-records seam for session and word-list history, daily activity, and study counts; append/prune stamps local dates and enforces the 20-day history window                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Settings presentation | `src/core/host/settingsPageRenderer.ts`, `src/core/host/settingsTab.ts`, `src/core/settings/presentation.ts`                                                                             | Renderer-neutral settings snapshots and opaque action refs; the tab adapter owns section lifecycle/refresh skipping, while `SettingsPageRenderer` owns the DOM (nav, controls, scroll/focus restoration, failure-preserving rebuilds)                                                                                                                                                                                                                                                                                                                                                                    |
| Video player          | `src/features/video-player/ui/playerViewInteraction.ts`, `src/features/video-player/domain/videoPlayerRuntime.ts`                                                                        | The player surface's DOM behavior (focus, shortcuts, interactive-target rule, pointer/drag, dock/floating, presenter role); runtime-owned playback/queue/persistence without DOM ownership                                                                                                                                                                                                                                                                                                                                                                                                               |
| Flashcard routing     | `src/features/flashcards/ui/routes.tsx`, `src/features/flashcards/ui/pageTransition.ts`                                                                                                  | Route constructors and the `ViewState` vocabulary, the page row table (resting routes + active/result surfaces), `resolvePage` with data-missing home fallback, and the page enter direction tracker                                                                                                                                                                                                                                                                                                                                                                                                     |
| Presentation models   | `src/features/flashcards/domain/history/`, `src/features/flashcards/domain/wordList/`, `src/features/flashcards/settings/`                                                               | Pure display definitions, derived presentation state, and history retention pruning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Flashcard strings     | `src/features/flashcards/strings/`                                                                                                                                                       | The 闪卡 dictionary (shared workbench strings merged with its own), the practice-message defaults, and the duration/rating formatters                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Dictionary            | `src/features/dictionary/domain/`                                                                                                                                                        | Dictionary lookup, local compiled dictionaries, sandbox rendering, and the compiled-v2 package authority                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Dictionary query      | `src/features/dictionary/domain/querySession.ts`                                                                                                                                         | Independent query input/state, history ordering, source concurrency, superseded-work cancellation, retries, explicit AI definitions, and immutable presentation snapshots                                                                                                                                                                                                                                                                                                                                                                                                                                |
